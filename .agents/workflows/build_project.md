# Build Project Workflow

Follow these steps to install dependencies, verify TypeScript types, and compile the Next.js application:

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run TypeScript Typecheck**:
   ```bash
   npm run typecheck
   ```

3. **Build the Application**:
   ```bash
   npm run build
   ```
